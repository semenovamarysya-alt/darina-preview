# Darina Preview

Public visual-only preview for the Darina Ermak Interiors project.

This repository intentionally contains no admin authentication, private Netlify functions, or project secrets.

## One-click local preview on Windows

1. Download or clone this repository.
2. Double-click `run.bat`.
3. On the first launch it installs dependencies automatically.
4. Your browser opens at `http://localhost:5173`.

If the folder was cloned with Git, `run.bat` also runs `git pull --ff-only` before starting, so the newest preview is loaded automatically.

You need Node.js LTS installed on Windows.
